# Torre de Controle — Painel Operacional

Dashboard interativo de controle operacional para transportadora, com dados simulados.

## Seções
- Visão Geral (OTD, sinistralidade)
- Operacional (visibilidade ponta a ponta, viagens em andamento, checklist de saída)
- Compliance, Fiscal e ANTT (CT-e, MDF-e, CIOT, piso mínimo de frete)
- Atendimento via WhatsApp
- Indicadores de desempenho

## Como publicar (GitHub Pages)
1. Crie um repositório novo no GitHub.
2. Faça upload do arquivo `index.html` deste pacote para a raiz do repositório.
3. Vá em **Settings → Pages**, selecione a branch `main` e a pasta `/root`, e salve.
4. Em alguns minutos o site estará disponível em `https://SEU-USUARIO.github.io/NOME-DO-REPO/`.

Todos os dados exibidos são simulados, para fins de demonstração.
